# School Surfers 🏃

Браузерный endless-runner в духе Subway Surfers: Максоген улепётывает по школе от Гендоса. Три дорожки, прыжки, подкаты, монеты, пули, джетпак и люк в туннель.

## Стек

| Слой | Технология |
| --- | --- |
| 3D-движок | [Three.js 0.160](https://threejs.org) через CDN + `importmap`, без бандлера и сборки |
| Логика | Vanilla JS, ES-модули (`type="module"`) |
| Персонажи/предметы | Billboard-спрайты (`THREE.Sprite` / `PlaneGeometry` + `lookAt`) поверх PNG из `sprites/` |
| Мир | Процедурная генерация: `BoxGeometry`/`CylinderGeometry`/`CanvasTexture`, ресайкл объектов |
| UI | Чистый HTML/CSS, без фреймворков |
| Запуск | Любой статический сервер (ES-модули + текстуры требуют HTTP, `file://` не подойдёт) |

Никаких `npm run build`, зависимостей в проде нет — склонировал, поднял сервер, играешь.

## Архитектура

```
index.html (сцена, HUD, оверлеи: меню / катсцена / пауза / game over)
  └── js/main.js         Game: цикл, состояния, ввод, камера, HUD
        ├── js/AssetsManager.js  загрузка sprites/, версии спрайтов стресса/злости
        ├── js/Level.js          мир: пол, препятствия, монеты, пикапы, пули, форд, дуэль
        ├── js/Player.js         Максоген: дорожки, прыжок, подкат, стресс, подуровни, разворот 360, HP
        ├── js/Guard.js          Гендос: дистанция догона, злость, стрельба, вспышки попаданий
        ├── js/Duel.js           QTE-дуэль: 3 раунда на кнопках, вспышки выстрелов
        ├── js/Extras.js         EXTRAS-книга: 3D-галерея, конструктор рана, темы
        ├── js/Models.js         фабрика всех 3D-моделек (Level + галерея)
        ├── js/Car.js            красный Ford Fusion-кабриолет + Игнатьевич за рулём
        ├── js/Skybox.js         кроссфейд фонов школы каждые ~25с (два задника)
        └── js/sfx.js            процедурные звуки WebAudio: клаксон, выстрелы, подбор, авария
```

### Поток кадра (`Game.animate`)

1. `Level.update` — мир едет на игрока (`+Z`): препятствия, монеты, пикапы, пол; тикают ивенты (предупреждение → выстрел), летят пули, тикает рост сложности.
2. `Guard.update` — Гендос догоняет (дистанция `8.0 → 1.1`), повторяет дорожку Максогена; на подуровнях ждёт.
3. `Player.update` — lerp между дорожками, физика прыжка, таймер подката/подуровня, лицо по стрессу.
4. `Level.checkCollisions / checkBullets` — сбор монет/пикапов, удары, попадания пуль.
5. `Game` — HUD, баннер ивентов, виньетка туннеля, проверка поимки, рендер.

### Состояния игры

`loading → menu → cutscene → playing ⇄ paused → gameover`. Катсцена в туалете — HTML-оверлей с диалогом, 3D-мир за ней крутится в idle-режиме.

### Модули

- **`AssetsManager`** — `THREE.TextureLoader` поверх `sprites/`. Порядок версий фиксирован индексами (колбэки асинхронны): `person[0..3]` = спокойствие → паника Максогена, `guard[0..2]` = спокойный → напряжённый (`sticker`) → злой. Монеты: `coin1` (+10), `coin2` (+50, щит 5с, отброс Гендоса).
- **`Level`** — фоном стоят школьные скайбоксы (`Skybox`), земля — процедурный линолеум (`CanvasTexture`). Препятствия: парта/книги/урна (прыжок), шкаф (объезд), турник (подкат) — у каждого `yRange` для честных вертикальных коллизий. Монеты — паттернами как в Subway Surfers (линии, арки над препятствиями, змейки, высокие линии), редко, но кучно; частота паттернов падает со временем, поэтому сигарет в минуту всегда одинаково. Бутылка — только mercy: одна, поштучно, когда шкала Гендоса почти на нуле (на НОРМЕ чуть раньше). Ствол спавнится сразу на 3 полосах (не скипнуть), siblings чистятся при подборе. Ресайкл через динамический фронт (`_frontZ`), без дрейфа в бесконечность. Сложность растёт со временем (`diffT` 0→1 за 3 мин): скорость, частота выстрелов/форда, короче варны, быстрее пули и форд, уже окна дуэли, злее догон.
- **`Car`** — процедурный красный Ford Fusion-кабриолет (крыши нет, салон открыт; Игнатьевич-физрук (`characters/sergey.png`) шириной в два сиденья — видно отлично). Плюс молдинги, ручки, антенна, дворники, выхлоп, 5-спицевые колёса, моргание фар. Ивент: клаксон → заезд по дорожке Максогена → на середине пути подруливание за игроком + ускорение и виляние → задел = проигрыш сразу или промазал (+25).
- **`Skybox`** — два задника 340×260, кроссфейд 3с каждые ~25с по списку `SKYBOX_FILES`.
- **`sfx`** — WebAudio без файлов, контекст по первому жесту игрока.
- **`Player`** — Максоген, учитель географии. 3 дорожки (`±2.6`), прыжок (`vy`, гравитация), подкат (squash спрайта), неуязвимость после удара. Здоровье: 5 ударов — конец рана (сердца в HUD). Стресс `0..1` от дистанции Гендоса → лицо `person1..4`, бег анимируется телом (bob + дыхание). Подуровни `tunnel` (`y −3.2`) / `fly` (`y +5`) на 6с с автовозвратом и щитом. Дуэль: подбор ствола → разворот на 360° → стойка зеркальным спрайтом (флаг `inDuel`, раунды ведёт `Duel`).
- **`Duel`** — QTE-дуэль: мир замирает, камера улетает за спину Максогена, 3 раунда (окна 1.8/1.4/1.1с). Верная кнопка — выстрел (+50, вспышка, Гендос отлетает), победа в 3 раундах — +150 и Гендос вдаль. Промах или таймаут — Гендос стреляет первым, ран кончается сразу.
- **`Extras`** — книга FNAF-стайл с тремя вкладками: 3D-галерея всех 14 моделек (отдельный рендерер, автоповорот + кручение пальцем/мышью, лор-описания), конструктор своего рана (9 слайдеров + тумблер «пуля = смерть», пресеты, сохранение в `localStorage`) и 5 тем интерфейса.
- **`Models`** — единая фабрика моделек (`buildObstacle`, `buildPickup`): Level строит мир из неё же, поэтому галерея показывает ровно то, что едет в игре.
- **`Guard`** — Гендос, учитель ОБЖ. Логическая дистанция + визуальная компрессия (всегда между камерой и игроком). Злость = близость + накопленный гнев: спрайт, размер и покраснение растут. Форсированная поза `guard2` с пистолетом на время ивента стрельбы. Со временем догоняет всё злее (`chaseBonus`).
- **`Game` (`main.js`)** — таблица режимов `MODES`, ввод через `e.code` (независим от RU/EN-раскладки) + свайпы и кнопки для мобильных, камера-follow с FOV-бустом от скорости, локальный рекорд в `localStorage`.

### Режимы сложности

| Режим | Скорость | Догон | Выстрелы | Форд |
| --- | --- | --- | --- | --- |
| НОРМА | 12 → 24 | базовый | каждые 10–18с | каждые 26–38с |
| СЛОЖНО | 15 → 30 | ×1.6 | каждые 7–12с | каждые 20–30с |
| НЕВОЗМОЖНО | 19 → 36 | ×2.3 | каждые 5–9с, пуля = смерть | каждые 16–26с |

Проигрыш: Гендос догнал, HP кончилось (5 ударов), задавил форд, пуля на НЕВОЗМОЖНО, проигранная дуэль.

Скорость, плотность препятствий, частота стрельбы и злость растут со временем забега на любом режиме.

## Запуск

```bash
# из корня проекта
python3 -m http.server 8812 --bind 127.0.0.1
# открыть http://127.0.0.1:8812/index.html
```

Управление: `A/D` или `←/→` — дорожка, `W/↑/Space` — прыжок, `S/↓` — подкат, `P/Esc` — пауза. На телефоне — свайпы и кнопки.

## Темы интерфейса

Вся UI-палитра — через CSS-переменные (`body[data-theme]`): Дефолт, Тёмная, Windows 98 (квадратные скошенные панели, Tahoma), Windows 7 (стеклянное aero), Неон (киберпанк). Переключение — в EXTRAS → Тема, выбор хранится в `localStorage`.

## Мобильная оптимизация

- Тач-кластеры под большие пальцы (◀ ▶ слева, ▲ ▼ справа), видны только во время игры; свайпы тоже работают.
- Адаптивное качество рендера: на тач-устройствах DPR ≤ 1.5, выключены MSAA и shadow-карта (теней в сцене нет, только blob-тени мешами).
- Камера отъезжает и расширяет FOV на узком портретном экране, чтобы крайние дорожки не обрезались.
- `viewport-fit=cover` + `safe-area-inset` под чёлку, `100dvh`, ресайз через `visualViewport` (плавающая URL-плашка).
- Wake Lock против гаснущего экрана, автопауза при сворачивании, кнопка полноэкранного режима ⛶.

## Проверка логики без браузера

Игровые классы не зависят от DOM (кроме `document.createElement('canvas')` для текстуры пола), поэтому спавн, коллизии и баланс можно гонять в Node с реальным `three` + стабами:

```bash
npm i three@0.160.0
node --check js/*.js
```
